Notepad Application

Completed
Notepad Wiki Repository

Tech Stack: C#, .NET 8, WPF, Serilog

  • Built a custom Notepad application using .NET 8 and WPF, focusing on clean UI and simple file handling.
  • Added a Settings window that lets users switch the logging level between Information and Debug. The UI updates based on the current log level.
  • Implemented a LoggingData service using Serilog with a LoggingLevelSwitch so the app can change log levels at runtime without restarting.
  • Configured Serilog to write logs to a daily rolling file with timestamps and structured formatting.
  • Created a FileService class that tracks the current file path, file name, file type, and whether a file is loaded. It also provides a default Downloads folder path.
  • Used simple properties like FileName, FileType, and HasFile to keep the UI logic clean and avoid redundant state.
  • Focused on learning WPF patterns, basic MVVM ideas, and how to connect UI controls to backend logic while keeping the code easy to follow.

Discord Bot – Game News Bot

Refactoring in Progress
Game News Bot Wiki Repository

Tech Stack: C#, .NET Framework 4.8, DSharpPlus, Serilog, Steam Web API, JSON (System.Text.Json)

  • Built a C# Discord bot on .NET Framework 4.8 using DSharpPlus, with separate modules for basic commands, game-news commands, and admin tools.
  • Added commands that fetch game news (TF2, Marvel Rivals, Risk of Rain, Palworld) from the Steam Web API, parse the JSON, and post the latest titles and URLs into the correct channels.
  • Used async/await for API calls and learned how to parse JSON responses using JsonDocument and EnumerateArray.
  • Created a channel-management service that automatically creates required news channels and a moderation log channel, stores their IDs, and updates the dictionary when channels are created, deleted, or changed.
  • Implemented simple moderation commands (Kick, Ban, Timeout) with permission checks and validation helpers to prevent actions like kicking bots or banning yourself.
  • Added basic utility commands such as Ping, Greet, and BotInfo, including an embed for cleaner bot information.
  • Integrated Serilog for structured logging and added commands to switch log levels inside the mod-log channel.
  • Learned how Discord lifecycle events work (GuildAvailable, GuildCreated, ChannelCreated, ChannelUpdated, ChannelDeleted) and used them to keep channel information in sync.
